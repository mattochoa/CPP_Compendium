# CPP Compendium (obsidian vault)

A conceptual atlas of C++, maintained by two scheduled agents and its owner.

| Path | What |
|---|---|
| `CPP Compendium/` | The Obsidian vault. Open this folder in Obsidian. Start at **Home**. |
| `CPP Compendium/00 System/` | Charter (strategy), Framework, Style Guide, Visual Language, Run/Audit Protocols, Directives, Ledger, Briefs, templates, dashboards |
| `tools/cc.py` | The toolkit CLI (`python3 tools/cc.py --help`) |
| `tools/data/` | Topic registry (`topics.yaml`), domains, archetype specs, book catalogue + TOCs |
| `tools/state/state.json` | Run counters and history |
| `.cache/` | Git-ignored: extracted book text, copy-guard index, run lock |

**Books** in `CPP Compendium/__RESOURCES__/` are git-ignored on purpose. They are used for research only; notes paraphrase and cite them.

Enable the CSS snippet **compendium** in Obsidian → Settings → Appearance → CSS snippets for the visual language (custom callouts).
